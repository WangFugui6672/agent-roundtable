# Agent Roundtable v0.1.0

Agent Roundtable 的第一个 MVP 版本：三个固定立场的 AI Agent 在 iOS App 和 Django 后端之间完成两轮结构化讨论，用户可插话、点名、暂停、恢复、提前结束并生成结论卡。

## 主要能力

- iOS 17+ SwiftUI 原生客户端，固定方案派、质疑派和体验派三个 AI 参与者。
- BYOK：Qwen、DeepSeek 和自定义 OpenAI-compatible Provider；API Key 只保存在 iOS Keychain。
- iOS 直连 Provider 流式生成；Django 签发 turn、校验引用、限制轮数/时间/消息数并保存事件。
- 用户消息、显式点名、暂停边界、继续与提前结束。
- 第二轮引用式互评，支持支持、质疑、补充和追问。
- 断线按游标补发、SwiftData 缓存、进程终止恢复和后台暂停。
- 结论版本化、继续追问、原生结论卡保存与系统分享。
- Provider 失败、超时、限流、预算耗尽和稳定错误形状。
- 本地内容规则、AI 标识、消息举报、本地隐藏、圆桌删除和 90 天保留。
- PostgreSQL 持久化、Redis Channels 广播、完整 Docker Compose 运行栈。

## 安装与运行

### 后端

需要 Docker 与 Docker Compose。

```bash
cp .env.example .env
docker compose up --build --detach --wait
curl http://127.0.0.1:8000/api/v1/health
```

默认宿主机端口为 `8000` 和 `5432`。端口冲突时在 `.env` 覆盖：

```dotenv
BACKEND_PORT=18000
POSTGRES_PORT=55432
```

公开部署前必须替换 `DJANGO_SECRET_KEY`、数据库密码并配置 HTTPS/WSS。

### iOS

需要 Xcode 16+、XcodeGen 和 iOS 17+ 模拟器。

```bash
brew install xcodegen
make ios-project
open ios/AgentRoundtable.xcodeproj
```

后端默认地址是 `http://localhost:8000`。真机调试时通过 Scheme 环境变量 `RT_API_BASE_URL` 指向可访问的 HTTPS/WSS 后端。

首次真实模型调用前会展示第三方数据提示。Mock 模式不需要 API Key。

## 已知边界

- 真实模型调用依赖用户自己的 Provider Key、网络、额度和服务条款；Django 无法验证实际 Token 账单。
- 客户端上报 Token 只用于预算保护，不是服务端精确计费依据。
- 内容规则是本地有限第一道过滤，不等同于模型审核或人工审核。
- 90 天清理由部署环境定时调用 `purge_roundtables`，仓库提供命令和 Compose `ops` profile，不内置调度器。
- 结论由模型生成，后端只能验证结构与引用归属，不能证明自然语言绝对没有隐含新事实。
- 结论卡支持本地保存和系统分享，不提供公开链接、二维码或房间导入。
- UI 自动化覆盖模拟器和 Mock 主流程；真实第三方 Provider 的账号、账单和地区可用性不在 CI 中验证。
- Android 客户端不在本版本范围内。
